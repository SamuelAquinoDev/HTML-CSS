Principais formatações

Negrito

Nessa frase, temos um termo em negrito usando a tag "B", que é uma tag não semântica. Ou seja, ela não tem significado, apenas forma (Negrito)

Já nessa frase, temos um termo em negrito usando a tag STRONG, que é semântica e possui significado

Itálico

Nesta frase, temos um termo em itálico usando a tag "I", que não é uma tag semântica, ou seja, não possui um significado

Já nesta frase, temos um termo em itálico usando a tag "EM", que é uma tag semântica, portanto possui um significado

Uma dica:
Para significado: HTML. Para forma: CSS

Texto marcado

Podemos também criar um texto marcado ao usar a tag "mark"

Para mudar a cor do texto marcado, usamos o "style", do CSS

Texto grande e pequeno

Estamos criando um texto grande e um texto pequeno neste parágrafo, usando as tags "big" (não semântica) e "small" (semântica)

Mas por que o texto grande foi instinto e o texto pequeno não?
Isso provavelmente aconteceu porque textos grandes não tem um sentido bem definido. Em que textos grandes são usados? não há uma explicação lógica pra isso.
Já os textos pequenos, por sua vez, podem ser usados em observações de contratos, as famosa "Letras pequenas".

Texto deletado

Podemos marcar um texto como excluído para mostrar que ele deve ser lido, mas não considerado

Texto inserido

Podemos marcar um texto como incluído/inserido para indicar que ele foi adicionado depois

Há também a possibilidade de tornar um texto sublinhado, exatamente da mesma forma que a tag "ins". Essa forma não semântica é usando a tag "u"

Texto sobrescrito

Para inserir coisas do tipo x20+3, usamos a tag "sup"

Texto subscrito

Para inserir coisas do tipo H2O, usamos a tag "sub"

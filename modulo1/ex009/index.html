Uma Lista ordenada, ou Ordered List, é feita usando a tag "ol"


Há também uma forma de mudar o tipo de cada Ordered List. Depois de "ol" é possível colocar a variável "type", e para a "ol" existem 4 types além do padrão:

ol type = "A"

  1. Acordar
  2. Tomar água
  3. Tomar banho
  4. Tomar café
  5. Trocar de roupa
  6. Ir pra escola
  7. Voltar pra casa

    8. etc...

Uma list não-ordenada, ou Unordered List, é feita com a tag "ul".


Há também as variações de "ul":

ul type = "square"

  • Pão
  • Queijo
  • Carne moida de patinho
  • Azeite

ul type = "circle"

  • Pão
